# Rsantos Open Source Toolkit

Biblioteca de ferramentas open source para inteligência artificial, automação, produtividade, criação de conteúdo e desenvolvimento.

**Responsável:** [@rsantos2912](https://github.com/rsantos2912)

## Objetivo
Estudar, testar, documentar e aplicar ferramentas abertas em projetos reais da Rsantos.MKT.

## 10 projetos catalogados

| Projeto | Categoria | O que faz |
|---|---|---|
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | Mídia | Baixa vídeos e extrai áudio de sites compatíveis. |
| [Ollama](https://github.com/ollama/ollama) | IA | Executa modelos de inteligência artificial localmente. |
| [Fooocus](https://github.com/lllyasviel/Fooocus) | Imagens | Gera imagens com inteligência artificial. |
| [Whisper](https://github.com/openai/whisper) | Áudio | Transcreve áudio em texto. |
| [Plausible](https://github.com/plausible/analytics) | Analytics | Analisa visitas e tráfego de sites. |
| [AppFlowy](https://github.com/AppFlowy-IO/AppFlowy) | Produtividade | Organiza documentos, tarefas e projetos. |
| [Penpot](https://github.com/penpot/penpot) | Design | Cria interfaces, layouts e protótipos. |
| [n8n](https://github.com/n8n-io/n8n) | Automação | Conecta aplicativos e automatiza tarefas. |
| [Cal.diy](https://github.com/calcom/cal.diy) | Agendamento | Organiza reuniões e agendamentos. |
| [Bitwarden](https://github.com/bitwarden/server) | Segurança | Gerencia senhas e credenciais. |

## Nossa ordem de implementação

1. Ollama — testar inteligência artificial local.
2. Whisper — transcrever narrações e criar legendas.
3. n8n — automatizar processos da Rsantos.MKT.
4. AppFlowy — organizar clientes e projetos.
5. Penpot — desenvolver interfaces e protótipos.

## Computador de referência

- GPU: NVIDIA RTX 3050.
- RAM: 16 GB.
- Sistema: Windows.

Os modelos de IA precisam ser escolhidos conforme a memória disponível e os requisitos de cada ferramenta.

## Cuidados importantes

- Verifique a licença de cada projeto antes de utilizar comercialmente.
- Open source não significa necessariamente ausência de custos.
- Não publique senhas, tokens ou dados de clientes.
- Respeite os direitos autorais dos conteúdos baixados.
- Verifique a manutenção e a segurança antes de instalar qualquer ferramenta.

## Objetivo final

Construir um laboratório de ferramentas open source para desenvolver soluções de inteligência artificial, automação e marketing digital.
